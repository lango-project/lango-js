# Lango Programming Language

## Design Goals

  * AI to write, humans to read.
  * Don't be wordy or cryptic.
  * Sometimes repeat things for better understanding.
  * Pragmatic: JSON, XML, SQL are first class citizens.
  * Compatible with Javascript.
    * Historical bad features like ==, === should be eliminated.

## Technology

  * Javascipt transpiler.
  * Connect seamlessly with existing libraries.
