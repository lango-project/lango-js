# Lango application

## Start

```sh
npm install
npm run run
```

## Commands

* `npm run build` compiles `src/main.lango` to `dist/main.mjs`.
* `npm run run` runs the Lango entry point.
* `npm run test` runs Lango test blocks under `test/`.
* `npm run format` formats the starter source file.

Install the **Lango** VS Code extension for syntax highlighting, diagnostics,
and document formatting.
